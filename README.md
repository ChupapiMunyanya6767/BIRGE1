# BIRGE — a quieter way to meet

A static, GitHub Pages-ready research site for the final project. It contains the four assignment sections, original visualisations, a source ledger, and an AI transparency statement. BIRGE is a proposal; the page does not implement a dating or mental-health service.

## Preview

Open `index.html` in a browser. The page uses no build system or JavaScript packages. A network connection is only needed for the optional Google Fonts; system fallbacks are included.

## Publish with GitHub Pages

1. Create a public GitHub repository for the project and add `index.html`, `styles.css`, `script.js`, and this `README.md` at the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the link shown on the Pages settings screen.

## Project scope

Working name: BIRGE. Proposed audience: adults aged 18–34 in Kazakhstan, a subset of the national youth-policy category of 14–35. Proposed use: opt-in introductions for friendship, romance, or either. Ten daily introductions are free; a ₸4,000 monthly subscription raises the cap to 30 total. Ads may help cover expenses, but sufficiency is unknown. The concept does not claim to prevent suicide, treat depression, or measure a user's mental-health risk. The proposed staged pilot starts only after the first four safeguards are independently reviewed and funded, and continues only if pre-set evaluation criteria are met.
